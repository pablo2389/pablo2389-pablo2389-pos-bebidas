# POS Bebidas SaaS - Para kioscos de barrio

**Demo:** https://pablo2389-pablo2389-pos-bebidas.vercel.app
**Stack:** FastAPI + Next.js + Supabase + WhatsApp

Kiosco de Las Heras tenía Excel para stock. Ahora carga producto, vende y el ticket le llega al WhatsApp del cliente sin pagar API mensual.

### Cómo correrlo
`cd bebidas-api && uvicorn main:app --reload`
`cd frontend && npm run dev`
